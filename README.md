# Jenny Slyder Website Deployment

Upload these files to the root of the GitHub repository used for GitHub Pages.

## Included

- `index.html`
- `styles.css`
- `assets/jenny-slyder-hero.png`
- `assets/jenny-slyder-promo.jpg`
- `private/index.html`
- `private/dashboard.html`
- `files/.gitkeep`

## Private Login

URL after deployment:

`https://jennyslyder.com/private/`

Default access code:

`jenny2026`

This is a light static login only. It is suitable for promoter materials, but it is not true secure authentication.

## Uploading the General Setlist

Upload your PDF to:

`files/general-setlist.pdf`

The private dashboard already links to it.

## Change Booking Email

In `index.html`, find:

`mailto:booking@example.com`

Replace it with the correct booking email.
